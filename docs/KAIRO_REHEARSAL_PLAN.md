## Implementation notes

All 14 storyboard cards are unverified references. This work extends the existing After Hours workbench. Keep the viewport and timeline unchanged in hierarchy and show the evaluated actor and station state in the existing inspector. Use short router view transitions on page content with reduced-motion support.

Persist the initialization mode in the library so a restart before first publication cannot seed the fictional office. Preserve the existing fictional seed digest. Use a separate local library for the Kairo draft and a disposable library for test acceptance.

Version 2 records the owner-checked Mesh Foundry identity on import. The owner enters the expected model-stage IDs and GLB hash from the authoritative project record. The service rejects a bundle that selects a different model. The local store keys provenance by exact Mesh Foundry identity and deduplicates GLB bytes by hash. New bindings can pin the source key explicitly. Existing hash-only bindings keep resolving to their original source.
